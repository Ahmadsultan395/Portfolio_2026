# Images

## Portrait (hero)

Save your photo as **`public/images/portrait.jpg`** (also accepted: `.jpeg`, `.png`, `.webp`, `.avif`).

- Best results: a portrait-orientation photo (about 4:5), at least 1000px wide, subject in the upper half, plain or dark background.
- The site detects the file at build time, so redeploy (or restart `npm run dev`) after adding it.
- Until it exists, an "MA" monogram is shown instead.

## Project screenshots (optional)

Save screenshots as `public/images/projects/<slug>.webp` (or `.jpg` / `.png`), 16:10 works best. Slugs:

- `digital-school-management-system`
- `dubai-safari-booking-platform`
- `enterprise-real-estate-marketplace`
- `khatri-brothers-academy`

Without a screenshot, a CSS-generated typographic graphic is shown.
